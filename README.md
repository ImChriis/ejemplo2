# Vidal Arteaga Abogados (maqueta)

Web de despacho de abogados en HTML, CSS y JavaScript sin dependencias de compilación.
Fuentes de Google Fonts e iconos de Phosphor cargados por CDN.

```bash
python -m http.server 5520
```

Abrir `http://localhost:5520`.

## Estructura

- `index.html`: contenido y secciones.
- `css/styles.css`: tokens de diseño, layout y animaciones (todas respetan `prefers-reduced-motion`).
- `js/main.js`: navegación, contadores, revelado al hacer scroll, carrusel arrastrable, vista previa de casos, opiniones y validación del formulario.

El despacho, las personas, los asuntos, las opiniones y las cifras son ficticios. El formulario no envía datos.
